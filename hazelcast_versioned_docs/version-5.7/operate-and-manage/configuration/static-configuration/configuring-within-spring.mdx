If you use Hazelcast with [Spring](https://spring.io/) you can declare beans using the namespace `hazelcast`. When you add the namespace declaration to the element `beans` in the Spring context file, you can start to use the namespace shortcut `hz` to be used as a bean declaration. See [Configuring Hazelcast in Spring](../../../frameworks-and-plugins/spring/configuration.mdx) for information on the configuration of Hazelcast-Spring integration.
