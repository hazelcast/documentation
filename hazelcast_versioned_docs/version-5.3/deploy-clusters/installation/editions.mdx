Hazelcast offers Enterprise and Open Source editions of its member software, each available as either a full or slim distribution.

## Enterprise Edition

Hazelcast Enterprise edition is a commercial product that extends the Open Source offering to provide you with many benefits, including the security suite, blue/green deployments for clients, and a [Hazelcast Customer Support](../../get-started/support.mdx#customer-support.adoc) subscription.

:::tip

In this documentation, topics related to an Enterprise edition feature include an <Badge type="enterprise"/> label.

:::

The Enterprise edition offers the following features, which are not available in the Open Source edition:

- [Security suite](../../configure-and-manage-clusters/securing-a-cluster/overview.mdx)
- [WAN Replication](../../configure-and-manage-clusters/synchronizing-data-across-clusters/wan.mdx)
- [Configuring CP Subsystem](../../configure-and-manage-clusters/cp-subsystem/configuration.mdx)
- [Deploying in Openshift container platform](../kubernetes/deploying-in-kubernetes.mdx)
- [Clustered REST](../../configure-and-manage-clusters/maintaining-a-cluster/monitoring.mdx#clustered-jmx-and-rest-via-management-center)
- [Clustered JMX](../../configure-and-manage-clusters/maintaining-a-cluster/monitoring.mdx#clustered-jmx-and-rest-via-management-center)
- [Rolling upgrades](../../configure-and-manage-clusters/maintaining-a-cluster/rolling-upgrades.mdx)
- [High-Density Memory Store](../../configure-and-manage-clusters/improving-cluster-performance/high-density-memory.mdx)
- [Persisting Data on Disk](../../configure-and-manage-clusters/configuring-for-fault-tolerance/persistence/persistence.mdx)
- [Blue/Green client support](../../develop-solutions/connecting-to-a-cluster/java.mdx#blue-green-deployment-and-disaster-recovery)

All pre-existing Hazelcast licenses, such as the Pro/Enterprise/Enterprise HD licenses, are valid for Hazelcast Platform.

## Full and Slim Distributions

<Anchor id="full-slim"/>

The following installation options offer a full and slim distribution:

- Docker
- ZIP/TAR Binaries
- Java

Other installation options offer only the full distribution.

You can find more information on installing the Hazelcast editions in the following topics:

- For the Enterprise edition, see the [Installing Hazelcast Enterprise](./install-enterprise.mdx) topic
- For the Open Source edition, see the [Installing Hazelcast Open Source](./install-hazelcast.mdx) topic

### Full Distribution

The full distribution contains all available Hazelcast connectors, libraries, and Management Center.

<details>
<summary>Full distribution content explanation</summary>

- `bin` — utility scripts for application management
- `config` - application configuration files (including reference examples)
- `lib` — application and dependency binaries
- `licenses` — application and dependency licenses
- `management-center` — bundled Management Center distribution

</details>

### Slim Distribution

The slim distribution allows you to save memory by excluding Management Center and connectors. You add the additional components as required.

To install a slim distribution, you can use any of the available installation options by appending `-slim` to the version number in the command; for example, to install the slim distribution of <Variable name="full-version"/>, use <code><Variable name="full-version"/>{"-slim"}</code>.

<details>
<summary>Slim distribution content explanation</summary>

- `bin` — utility scripts for application management
- `config` - application configuration files (including reference examples)
- `lib` — application and dependency binaries
- `licenses` — application and dependency licenses

</details>
