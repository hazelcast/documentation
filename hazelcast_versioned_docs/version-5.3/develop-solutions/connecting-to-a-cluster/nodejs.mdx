Node.js Client implementation for Hazelcast. It is implemented using the Hazelcast Open Binary Client Protocol.

See Hazelcast Node.js client's GitHub [repo](https://github.com/hazelcast/hazelcast-nodejs-client) for its documentation and [code samples](https://github.com/hazelcast/hazelcast-nodejs-client/tree/master/code_samples).
