The Hazelcast Command-Line Client (CLC) is a command-line tool that allows you to connect to and interact with clusters on Hazelcast Platform and <a href="/cloud/overview">Hazelcast <Variable name="hazelcast-cloud"/></a>. You can use the CLC to execute commands through a terminal. See its documentation for [example use cases](/clc/latest/overview#use-cases), [tutorials](/clc/latest/get-started), and [supported commands](/clc/latest/clc-commands).
