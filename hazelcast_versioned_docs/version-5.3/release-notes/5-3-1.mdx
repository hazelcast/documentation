## Enhancements

- Updated the version of `jackson-core` dependency to 2.15.2. [\#24727](https://github.com/hazelcast/hazelcast/pull/24727)

## Fixes

- Fixed an issue where submitting a job was failing when it is done using Hazelcast Command-Line Client (CLC). [\#24704](https://github.com/hazelcast/hazelcast/pull/24704)
- Fixed an issue where the REST calls were failing for Hazelcast clusters with TLS v1.3 configured, and deployed on Kubernetes. [\#24623](https://github.com/hazelcast/hazelcast/pull/24623)
- Fixed various issues in [Health Monitor](../configure-and-manage-clusters/maintaining-a-cluster/monitoring.mdx#health-monitor) including incorrect metric names. [\#24636](https://github.com/hazelcast/hazelcast/pull/24636)
