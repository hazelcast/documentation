## Fixes

- Fix memory leak with OpenSSL (with newer versions of netty libraries) \#13738
- Fix Jet vulnerabilities

  - Fix [CVE-2022-3171](https://github.com/advisories/GHSA-h4h5-3hr4-j3g2) vulnerabilities in protobuf-java 3.19.4 and hadoop-shaded-protobuf\_3\_7-1.1.1 [\#22541](https://github.com/hazelcast/hazelcast/issues/22541)
  - Fix [CVE-2023-2976](https://github.com/advisories/GHSA-7g45-4rm6-3mm3) vulnerability in hadoop-shaded-guava-1.1.1.jar (shaded: com.google.guava:guava:30.1.1-jre) [\#24981](https://github.com/hazelcast/hazelcast/issues/24981)
  - Fix [CVE-2024-36114](https://github.com/advisories/GHSA-973x-65j7-xcf4) vulnerability in aircompressor-0.21 [\#26354](https://github.com/hazelcast/hazelcast/issues/26354)
- Fix serialization issue with rolling upgrade from 5.2 to 5.3
- Fix phone home metrics for vCPUs
