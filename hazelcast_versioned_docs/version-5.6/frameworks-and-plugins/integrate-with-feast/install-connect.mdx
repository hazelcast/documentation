Before you can use Feast with Hazelcast as an online store, you must install Feast and connect to Hazelcast.

## Install Feast

<PartialIntegrateFeastInstall/>

```console
pip install 'feast[hazelcast]'
```

## Connect to Hazelcast

<PartialIntegrateFeastConnect/>

```console
feast init REPO_NAME -t hazelcast
```
