![Hazelcast Overview](./images/hazelcast-overview.png)

Welcome to the documentation for Hazelcast Platform, the leading in-memory data grid and compute platform for building real-time applications.

Hazelcast Platform combines a fast data store and powerful stream processing into a single platform, eliminating latency moving data between databases and processing.

Hazelcast offers <a href="/hazelcast/5.6/getting-started/get-started-enterprise"><Variable name="enterprise-product-name"/></a> and <a href="/hazelcast/5.6/getting-started/get-started-docker"><Variable name="open-source-product-name"/></a> versions of Hazelcast Platform with a range of deployment options, including Docker and Kubernetes. You can get started with either version by following the quickstarts below.

Hazelcast <Variable name="enterprise-product-name"/> is a licensed product that extends the <Variable name="open-source-product-name"/> to provide many additional [features and benefits](./editions.mdx#key-features-and-benefits) for production environments, including regular patch releases and a [support](./support.mdx) subscription.

Hazelcast is implemented in Java (with choice of embedded or client/server mode) and has [clients](../clients-and-apis/client-overview.mdx) for Java, C++, .NET, REST, Python, Go and Node.js. Hazelcast also speaks Memcache and REST protocols.
