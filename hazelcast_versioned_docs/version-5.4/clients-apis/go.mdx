Go Client implementation for Hazelcast. It is implemented using the Hazelcast Open Binary Client Protocol.

See Hazelcast Go client's GitHub [repo](https://github.com/hazelcast/hazelcast-go-client) for its documentation and [code samples](https://github.com/hazelcast/hazelcast-go-client/tree/master/examples).
