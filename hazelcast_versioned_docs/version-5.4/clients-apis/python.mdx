Python Client implementation for Hazelcast. It is implemented using the Hazelcast Open Binary Client Protocol.

See Hazelcast Python client's GitHub [repo](https://github.com/hazelcast/hazelcast-python-client) for its documentation and [code samples](https://github.com/hazelcast/hazelcast-python-client/tree/master/examples).
