This topic describes how to remove Management Center using the Hazelcast Platform Operator for Kubernetes.

## Remove Management Center

To remove the Management Center, run the commands below.

<Tabs groupId="k8s-platform">
<TabItem value="kubernetes" label="Kubernetes">

```shell
kubectl delete -f management-center.yaml
```

</TabItem>
<TabItem value="openshift" label="Openshift">

```shell
oc delete -f management-center.yaml
```

</TabItem>
</Tabs>
