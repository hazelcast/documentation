This release adds support to configure [User Code Namespaces](../deploy/user-code-namespaces.mdx) using the UserCodeNamespace CR.

## New Features

- Added support to configure User Code Namespaces using the `UserCodeNamespace` CR. [\#1091](https://github.com/hazelcast/hazelcast-platform-operator/pull/1091)

## Changes

- Added "thread name" to the logging pattern. [\#1117](https://github.com/hazelcast/hazelcast-platform-operator/pull/1117)
- Added `DefaultJavaOptions` and appended these options to the `JAVA_OPTS` environment variable. [\#1114](https://github.com/hazelcast/hazelcast-platform-operator/pull/1114)

## Fixed Issues

- Fixed the Webhook setup error in restricted mode. [\#1128](https://github.com/hazelcast/hazelcast-platform-operator/pull/1128)
- Fixed the `Failed to watch *v1.Node: unknown (get nodes)` warnings. [\#1115](https://github.com/hazelcast/hazelcast-platform-operator/pull/1115)
