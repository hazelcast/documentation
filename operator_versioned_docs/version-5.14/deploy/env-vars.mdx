title: "Configuring Environment Variables"
sidebar_position: 18
slug: /env-vars
---

You can configure the environment variables in the `hazelcast` pods using the `env` field of the CRD spec. `env` field supports the same format with [Kubernetes' EnvVar format](https://kubernetes.io/docs/reference/generated/kubernetes-api/v1.27/#envvar-v1-core/).

:::warning

You cannot use the `env` field to configure Hazelcast environment variables, which are prefixed `HZ_`. To configure the Hazelcast environment variables, use [Custom Config](./custom-config.mdx).

:::
