Hazelcast's distributed queue is an implementation of `java.util.concurrent.BlockingQueue`. Being distributed enables all cluster members to interact with it. Using Hazelcast distributed queue, you can add an item in one cluster member and remove it from another one. You can create and configure queues using the `Queue` custom resource.

## Configure a queue resource

You can use any of the following configuration options in the `Queue` resource. For more information, see the [API reference](../../../reference/api-ref.mdx#queuespec).

| Field | Description |
| --- | --- |
| `name` | Name of the queue that you're creating. If empty, the custom resource (CR) name is used. |
| `hazelcastResourceName` | The name of the Hazelcast resource. |
| `backupCount` | Count of synchronous backups. |
| `asyncBackupCount` | Count of asynchronous backups. |
| `maxSize` | Maximum size of the queue. |
| `emptyQueueTTLSeconds` | Time in seconds after which the queue will be destroyed if it stays empty or unused. If this field is not set, the queue will never be destroyed. |
| `priorityComparatorClassName` | The name of the comparator class. If the class name is provided, the queue becomes a priority queue. |
