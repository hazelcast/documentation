Before upgrading, you should read the information in the [rolling upgrade documentation](/hazelcast/latest/maintain-cluster/rolling-upgrades#hazelcast-members-compatibility-guarantees) for Hazelcast Platform.

Each Operator version has been tested with a specific Hazelcast Platform version as listed in the following table. You should use the appropriate version to avoid problems.

| Operator version | Hazelcast Platform version |
| --- | --- |
| 5.11 | 5.4.0 |
| 5.12 | 5.4.0 |
| 5.13 | 5.5.0 |
| 5.14 | 5.5.2 |
| 5.15 | 5.5.4 |
| 5.16 | 5.6.0 |
| 5.17 | 5.7.0 |
| 5.18 | 5.7.0 |

## Upgrade the deployment

To upgrade your existing Hazelcast deployment to a newer version, update the `spec.version` field and re-apply.

For example, if the following is the existing configuration:

```yaml vars
apiVersion: hazelcast.com/v1alpha1
kind: Hazelcast
metadata:
  name: hazelcast-sample
spec:
  clusterSize: 3
  repository: 'docker.io/hazelcast/hazelcast-enterprise'
  version: '{page-latest-supported-hazelcast}-slim'
```

Apply the following to upgrade your Hazelcast version to <Variable name="page-latest-supported-hazelcast"/>:

```yaml vars
apiVersion: hazelcast.com/v1alpha1
kind: Hazelcast
metadata:
  name: hazelcast-sample
spec:
  clusterSize: 3
  repository: 'docker.io/hazelcast/hazelcast-enterprise'
  version: '{page-latest-supported-hazelcast}-slim'
```
