Before upgrading, you should read the information in the [rolling upgrade documentation](/hazelcast/latest/maintain-cluster/rolling-upgrades#hazelcast-members-compatibility-guarantees) for Hazelcast Platform.

Each Operator version has been tested with a specific Hazelcast Platform version as listed in the following table. You should use the appropriate version to avoid problems.

| Operator version | Hazelcast Platform version |
| --- | --- |
| 5.11 | 5.4.0 |
| 5.12 | 5.4.0 |
| 5.13 | 5.5.0 |
| 5.14 | 5.5.2 |
| 5.15 | 5.5.4 |
| 5.16 | 5.6.0 |
