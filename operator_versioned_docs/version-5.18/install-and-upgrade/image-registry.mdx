Hazelcast images are hosted at `docker.io/hazelcast` and `registry.connect.redhat.com/hazelcast`. The Docker images are used by default.

When running in an air-gapped or offline environment, you must mirror the images to a private container image registry.

To access images hosted in a private registry or the Red Hat registry, you must set the image location for each application.

:::note

You will need to authenticate with a Red Hat account to access the Red Hat images.

:::

## Specify a non-default image

To set the image for each application, specify the repository URL, version tag, and authentication secret as shown in the following sections.

:::note

Hazelcast does not publish Red Hat images for `snapshot` versions.

:::

### Platform Operator

Specify the image details when running `helm install`:

```shell
helm install operator hazelcast/hazelcast-platform-operator --version=5.18.0 \
    --set=installCRDs=true \
    --set=image.repository=<REGISTRY_URL> \
    --set=image.tag=5.18.0 \
    --set=image.pullSecrets={<REGISTRY-SECRET>}
```

### Hazelcast Platform

Add the image details to the Hazelcast CR configuration:

```none
apiVersion: hazelcast.com/v1alpha1
kind: Hazelcast
metadata:
  name: hazelcast
spec:
  repository: <REGISTRY_URL>
  version: 5.7.0
  imagePullSecrets:
    - name: <REGISTRY_SECRET>
```

### Sidecar Agent

Add the image details to the Hazelcast CR configuration:

```none
apiVersion: hazelcast.com/v1alpha1
kind: Hazelcast
metadata:
  name: hazelcast
spec:
  imagePullSecrets:
    - name: <REGISTRY_SECRET>
  agent:
    repository: <REGISTRY_URL>
    version: 5.18.0
```

### Management Center

Add the image details to the Hazelcast CR configuration:

```none
apiVersion: hazelcast.com/v1alpha1
kind: ManagementCenter
metadata:
  name: managementcenter
spec:
  repository: <REGISTRY_URL>
  version: 5.11.0
  imagePullSecrets:
    - name: <REGISTRY_SECRET>
```
