Learn how to run a data pipeline in Hazelcast using Jet.

## Overview

In this tutorial, you'll:

- Build and deploy a custom Jet pipeline implementation to cloud storage.
- Deploy Hazelcast with the Jet engine configured.
- Start the Jet pipeline.
- Check the Jet pipeline.
- Cancel the Jet pipeline.

The tutorial should take approximately 20 minutes to complete.

## Prerequisites

Before you begin, make sure that you have:

- A running [Kubernetes](https://kubernetes.io/) cluster.
- The Kubernetes command line tool, [kubectl](https://kubernetes.io/docs/tasks/tools/#kubectl).
- The Maven command line tool, [mvn](https://maven.apache.org/download.cgi).
- Deployed [Hazelcast Platform Operator](../../../../install-and-upgrade/get-started/overview.mdx).
- The Hazelcast Code Samples repository [https://github.com/hazelcast/hazelcast-code-samples](https://github.com/hazelcast/hazelcast-code-samples) cloned to your local machine.
- Blob storage and access credentials on one of the following cloud providers: [AWS](https://aws.amazon.com/s3/), [GCP](https://cloud.google.com/storage/), [Azure](https://azure.microsoft.com/en-us/services/storage/blobs/).

## Deploy the Jet pipeline JAR to cloud storage

In this step, you'll build the Jet pipeline JAR from the tutorial's GitHub repository, and upload it to your cloud provider.

1. Clone the sample project.

   <Tabs groupId="https--ssh">
   <TabItem value="https" label="HTTPS">

   ```bash
   git clone https://github.com/hazelcast-guides/hazelcast-platform-operator-jet.git

   cd hazelcast-platform-operator-jet
   ```

   </TabItem>
   <TabItem value="ssh" label="SSH">

   ```bash
   git clone git@github.com:hazelcast-guides/hazelcast-platform-operator-jet.git

   cd hazelcast-platform-operator-jet
   ```

   </TabItem>
   </Tabs>

   The sample code for this tutorial is in the [`jet-pipeline/src/main/java/org/example/run/`](https://github.com/hazelcast-guides/hazelcast-platform-operator-jet/tree/master/jet-pipeline/src/main/java/org/example/run) directory.
2. Build the Jet pipeline JAR.

   ```shell
   mvn package -f ./jet-pipeline
   ```
3. Upload the Jet pipeline JAR to the storage blob/bucket of your cloud provider, replacing the placeholder values.

   <Tabs groupId="object-storage">
   <TabItem value="s3" label="S3">

   ```bash
   aws s3 cp jet-pipeline/target/jet-pipeline-run-1.0.0.jar s3://<BUCKET_NAME>
   ```

   </TabItem>
   <TabItem value="gcs" label="GCS">

   ```bash
   gsutil cp jet-pipeline/target/jet-pipeline-run-1.0.0.jar gs://<BUCKET_NAME>
   ```

   </TabItem>
   <TabItem value="abs" label="ABS">

   ```bash
   az storage blob upload --account-name <ACCOUNT_NAME> --container-name <CONTAINER_NAME> --file jet-pipeline/target/jet-pipeline-run-1.0.0.jar
   ```

   </TabItem>
   </Tabs>
4. Create a secret for your cloud storage.

   <Tabs groupId="cloud-provider">
   <TabItem value="aws" label="AWS">

   ```bash
   kubectl create secret generic <SECRET-NAME> --from-literal=region=<region> \
   	--from-literal=access-key-id=<access-key-id> \
   	--from-literal=secret-access-key=<secret-access-key>
   ```

   </TabItem>
   <TabItem value="gcp" label="GCP">

   ```bash
   kubectl create secret generic <SECRET-NAME> --from-file=google-credentials-path=<service_account_json_file>
   ```

   </TabItem>
   <TabItem value="azure" label="Azure">

   ```bash
   kubectl create secret generic <SECRET-NAME> \
   	--from-literal=storage-account=<storage-account> \
   	--from-literal=storage-key=<storage-key>
   ```

   </TabItem>
   </Tabs>

:::tip

If you want to learn more about other authentication methods, see [Authorization Methods to Access Cloud Storage](../../../security/authorization.mdx).

:::

## Start the Hazelcast cluster

1. Create a secret with your [Hazelcast Enterprise License](http://trialrequest.hazelcast.com/).

   ```shell
   kubectl create secret generic hazelcast-license-key --from-literal=license-key=<hz-license-key>
   ```
2. Create a Hazelcast cluster with the Jet engine configured.

   <CodeBlock language="shell">{'kubectl apply -f - <<EOF\n' + Ex_hazelcast_code_samples_platform_operator_hazelcast_platform_operator_jet_docs_modules_ROOT_examples_hazelcast_jet_yaml + 'EOF'}</CodeBlock>

   :::note

   You need to use Hazelcast 5.3 or above to submit Jet jobs with Operator.

   :::
3. Check the cluster status to make sure that it's up and running.

   ```shell
   kubectl get hazelcast my-hazelcast
   NAME           STATUS    MEMBERS
   my-hazelcast   Running   3/3
   ```

## Run the data pipeline

In this step, you'll start, check and cancel the Jet job that runs the data pipeline.

1. Start the Jet job you have already deployed:

   Replace the \<BUCKET-URI\> with the appropriate sample bucket URI for your cloud provider:

   - s3://hazelcast-jet-pipeline
   - gs://hazelcast-jet-pipeline
   - azblob://hazelcast-jet-pipeline

   <CodeBlock language="shell">{'kubectl apply -f - <<EOF\n' + Ex_hazelcast_code_samples_platform_operator_hazelcast_platform_operator_jet_docs_modules_ROOT_examples_jet_running_yaml + 'EOF'}</CodeBlock>
2. Check status of the Jet job.

   ```bash
   kubectl get jetjob my-jet-job -w
   ```

   The output will look something like this. Wait until the `Running` status appears.

   ```bash

   my-jet-job   Starting  0
   my-jet-job   Running   732187341048774657   2023-07-14T10:51:06Z
   ```
3. Check the output of the Jet pipeline in the logs:

   ```bash
   kubectl logs -l app.kubernetes.io/name=hazelcast -c hazelcast | grep sequence
   ```

   The logs of the Jet pipeline are displayed in the output.

4. Cancel the Jet job by setting the `spec.state` to `Canceled`. Use one of the following options.

   1. Cancel the Jet job using `kubectl apply`:

      <CodeBlock language="shell">{'kubectl apply -f - <<EOF\n' + Ex_hazelcast_code_samples_platform_operator_hazelcast_platform_operator_jet_docs_modules_ROOT_examples_jet_canceled_yaml + 'EOF'}</CodeBlock>
   2. Cancel the Jet job using `kubectl patch`:

      ```bash
      kubectl patch jetjob my-jet-job -p '{"spec":{"state":"Canceled"}}' --type=merge
      ```
5. Check the Jet job status to make sure the job was cancelled.

   ```bash
   kubectl get jetjob my-jet-job
   ```

   The output shows the Jet job status as `ExecutionFailed`.

   ```bash

   my-jet-job   ExecutionFailed   732229926463209474   2023-07-14T13:40:19Z   2023-07-14T14:07:51Z
   ```
6. See a more detailed message for the status of the Jet job:

   ```bash
   kubectl get jetjob my-jet-job -o custom-columns=:.status.failureText
   ```

## Clean up

To clean up all the resources you created during the tutorial, and to remove the custom resources and secrets, run the following command:

```shell
kubectl delete secret <SECRET-NAME>
kubectl delete $(kubectl get hazelcast -o name)
```

:::note

Deleting the Hazelcast CR also deletes the Jet jobs linked to it.

:::
