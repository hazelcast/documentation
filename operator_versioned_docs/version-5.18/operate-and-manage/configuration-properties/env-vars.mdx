---
title: "Configure Environment Variables"
sidebar_position: 1
slug: /env-vars
---

You can configure environment variables in the `hazelcast` pods using the `env` field of the CRD. The `env` field uses the [Kubernetes' EnvVar format](https://kubernetes.io/docs/reference/generated/kubernetes-api/v1.27/#envvar-v1-core/).

:::warning

You cannot use the `env` field to configure Hazelcast environment variables, which are prefixed `HZ_`. To configure Hazelcast environment variables, use [Custom configuration](/operator/5.18/custom-config).

:::
