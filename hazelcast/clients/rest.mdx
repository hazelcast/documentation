Hazelcast offers an HTTP REST client with which you can communicate with your cluster over HTTP using the REST approach. See the [REST API section](../maintain-cluster/rest-api.mdx) for details on its usage.

:::caution[Deprecation Notice for the Community Edition REST API]

The Community Edition REST API has been deprecated and will be removed as of Hazelcast version 7.0. An improved Enterprise version of this feature is available and actively being developed. For more information, see [Enterprise REST API](../clients-and-apis/apis/enterprise-rest-api/overview.mdx).

:::
