Hazelcast offers <Variable name="enterprise-product-name"/> and <Variable name="open-source-product-name"/> versions of Hazelcast Platform, each available as either a full or slim distribution, or via a number of package managers.

This page includes detailed information on features available with each edition, as well as information on licensing permissions.

## <Variable name="enterprise-product-name"/> versus <Variable name="open-source-product-name"/> {/* #enterprise-edition-versus-community-edition */}

Hazelcast <Variable name="enterprise-product-name"/> is a licensed product that extends the <Variable name="open-source-product-name"/> offering to provide many additional features and benefits, plus a [Hazelcast Customer Support](./support.mdx#customer-support.adoc) subscription.

:::tip

Get a free <Variable name="enterprise-product-name"/> trial from [Try Hazelcast](https://hazelcast.com/get-started/?utm_source=docs-website).

:::

Hazelcast <Variable name="open-source-product-name"/> is free and covered by an Apache License, Version 2.0, and a [Hazelcast Community License](https://hazelcast.com/hazelcast-community-license/?utm_source=docs-website). The permissions granted in these licenses allow you to do the following:

- Use the <Variable name="open-source-product-name"/>
- Reproduce the <Variable name="open-source-product-name"/>
- Distribute the <Variable name="open-source-product-name"/> with any open and/or closed source applications

:::note

<Variable name="enterprise-product-name"/> features are marked with an <Badge type="enterprise"/> label in this documentation. All pre-existing Hazelcast licenses, such as the Pro/Enterprise/Enterprise HD licenses, are valid for Hazelcast Platform. Each edition has its own installation file i.e. you can't turn a <Variable name="open-source-product-name"/> into an <Variable name="enterprise-product-name"/> by adding a license key.

:::

## Full and slim distributions

Full and slim distributions of <Variable name="enterprise-product-name"/> and <Variable name="open-source-product-name"/> are available as separate downloads from [hazelcast.com](https://hazelcast.com/?utm_source=docs-website). You will need a license key for either <Variable name="enterprise-product-name"/> distribution but <Variable name="open-source-product-name"/> distributions can be installed without a key.

:::tip

You can get a free <Variable name="enterprise-product-name"/> trial from [Try Hazelcast](https://hazelcast.com/get-started/).

:::

For more information on installing Hazelcast editions, see:

- For <Variable name="enterprise-product-name"/>, see [Install Hazelcast Enterprise Edition](../install-and-upgrade/enterprise-edition/install-enterprise.mdx)
- For <Variable name="open-source-product-name"/>, see [Install Hazelcast Community Edition](../install-and-upgrade/community-edition/install-hazelcast.mdx)

### Full distribution

The full distributions contain all available Hazelcast connectors and libraries, and Management Center.

<details>
<summary>Full distribution contents</summary>

- `bin` — utility scripts for application management
- `config` - application configuration files (including reference examples)
- `lib` — application and dependency binaries
- `licenses` — application and dependency licenses
- `management-center` — bundled Management Center distribution

</details>

### Slim distribution

The slim distributions exclude Management Center and connectors. You can add the additional components as required.

<details>
<summary>Slim distribution contents</summary>

- `bin` — utility scripts for application management
- `config` - application configuration files (including reference examples)
- `lib` — application and dependency binaries
- `licenses` — application and dependency licenses

</details>
