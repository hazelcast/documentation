### Example Apache Pulsar Data Connection {/* #Pulsar */}

<Tabs groupId="java--sql--xml--yaml">
<TabItem value="xml" label="XML">

```xml conums
<hazelcast>
  <data-connection name="my-pulsar">
    <type>Pulsar</type>
    <properties>
      <property name="brokerUrl">pulsar://pulsar.mydomain.com:6650</property> <1>
      <property name="httpServiceUrl">http://pulsar.mydomain.com:8080</property> <2>
    </properties>
    <shared>true</shared>
  </data-connection>
  <data-connection name="my-other-pulsar">
    <type>Pulsar</type>
    <properties>
      <property name="brokerUrl">pulsar://pulsar.mydomain.com:6650</property> <1>
      <property name="httpServiceUrl">http://pulsar.mydomain.com:8080</property> <2>
      <property name="tenant">myTenant</property> <3>
      <property name="namespace">myNamespace</property> <3>
      <property name="enableTransactions">true</property> <4>
      <property name="closeTimeoutSeconds">60</property> <5>
    </properties>
    <shared>true</shared>
  </data-connection>
</hazelcast>
```

<CodeCallouts>

1. (Required) Broker URL, mandatory property.
2. (Required) Broker HTTP Service, also used to list resources with `listResources`.
3. (Optional) Options to limit which resources are visible when querying for resource list using this `DataConnection` (call to `listResources`).
4. (Optional) If true, transactions will be enabled on the client. Default is false. Please note, that transactions must be first enabled in the broker configuration.
5. (Optional) How long, in seconds, a shared data connection waits for its underlying Pulsar client to close before forcing a shutdown. Defaults to 300 seconds.

</CodeCallouts>

</TabItem>

<TabItem value="sql" label="SQL">

Data connections created in SQL behave differently from those defined in members' configuration files or in Java.

- To retain SQL-defined data connections after a cluster restart, you must enable [SQL metadata persistence](../operate-and-manage/fault-tolerance/persistence/configuring-persistence.mdx#sql). This feature is available in the <Variable name="enterprise-product-name" />.
- You can create or drop a data connection using SQL commands. To update a data connection, you need to drop and then recreate it.

```sql conums
CREATE DATA CONNECTION my_pulsar
TYPE Pulsar
SHARED
OPTIONS (
    'brokerUrl' = 'pulsar://pulsar.mydomain.com:6650' <1>
    'httpServiceUrl' = 'http://pulsar.mydomain.com:8080 '<2>
)
```

<CodeCallouts>

1. (Required) Broker URL, mandatory property.
2. (Required) Broker HTTP Service, also used to list resources with `listResources`.

</CodeCallouts>

| Property | Default value | Description | When to use |
| --- | --- | --- | --- |
| `brokerUrl` |  | Pulsar Broker URL, in a form of `pulsar://myhost:port/` | Mandatory |
| `httpServiceUrl` |  | URL of Pulsar's instance HTTP service, typically on port 8080. Example: [`http://myhost:8080/`](http://myhost:8080/) | Mandatory. Also used to list resources with this data connection. |
| `tenant` |  | If set, it limits which resources (topics) will be listed to only those of given tenant. | Only if you want to restrict access to subset of topics. |
| `namespace` |  | If set, it limits which resources (topics) will be listed to only those of given namespace. | Only if you want to restrict access to subset of topics. |
| `enableTransactions` | false | Enables transaction for returned Pulsar Clients. | If you want to use transactions with clients returned by this Data Connection. **Must** be set to true if used with Pulsar sink / SQL "INSERT INTO" Pulsar topic with `EXACTLY_ONCE` processing guarantee. |
| `closeTimeoutSeconds` | 300 | How long a shared data connection waits for its underlying Pulsar client to close gracefully before forcing a shutdown. | Only if you want a shorter or longer wait than the default 5 minutes before falling back to a forced shutdown. Applies only to shared data connections. |
