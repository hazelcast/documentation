## Step 1. Add new configuration using /hazelcast/rest/api/v1/config/update endpoint

To update the configuration, send a POST request including the new data structure config in the request body as YAML or XML:

:::tip

You can also try this out using the Swagger UI. For more info, see the Swagger UI example below.

:::

<Tabs groupId="curl-with-xml--curl-with-yaml--using-swagger-ui">
<TabItem value="curl-with-xml" label="cURL with XML">

```shell conums
curl -X POST \
'http://localhost:8443/hazelcast/rest/api/v1/cluster/config/update' \
-H 'Content-Type: application/json' \
-H 'Authorization: Bearer '"$JWT_TOKEN"'' \ <1>
-d '<hazelcast xmlns="http://www.hazelcast.com/schema/config">
    <map name="my-map">
        <in-memory-format>BINARY</in-memory-format>
        <statistics-enabled>true</statistics-enabled>
        <backup-count>2</backup-count>
    </map>
    <queue name="my-queue">
        <max-size>10</max-size>
        <backup-count>2</backup-count>
    </queue>
</hazelcast>'
```

</TabItem>
<TabItem value="curl-with-yaml" label="cURL with YAML">

```shell conums
curl -X POST \
  'http://localhost:8443/hazelcast/rest/api/v1/cluster/config/update' \
  -H 'Authorization: Bearer '"$JWT_TOKEN"'' \ <1>
  -H 'Content-Type: application/json' \
  -d 'hazelcast:
  map:
    my-map:
      in-memory-format: BINARY
      statistics-enabled: true
      backup-count: 2
  queue:
    my-queue:
      max-size: 10
      backup-count: 2'
```

</TabItem>
<TabItem value="using-swagger-ui" label="Using Swagger UI">

- Open the Swagger UI at `http://localhost:8443/swagger-ui/index.html`.
- Navigate to the `/cluster/config/update` endpoint under the **Cluster Controller** section.
- You must already have saved the authorization token as documented in [Step 4](./get-started-rest-api-with-docker.mdx#step-4-obtain-a-token-to-access-all-endpoints) of the REST API "Getting started" tutorials.
- Click **Try it out**.
- Set the request body as follows (YAML example shown but either YAML or XML can be used):

  ```yaml
  hazelcast:
    map:
      my-map:
        in-memory-format: BINARY
        statistics-enabled: true
        backup-count: 2
    queue:
      my-queue:
        max-size: 10
        backup-count: 2
  ```
- Click **Execute**.

</TabItem>
</Tabs>

<CodeCallouts>

1. Set the JWT\_TOKEN as environment variable or replace it with your token directly in the command.

</CodeCallouts>

Here is the expected response body:

```json
{
  "addedConfigs": [
    {
      "sectionName": "map",
      "configName": "my-map"
    },
    {
      "sectionName": "queue",
      "configName": "my-queue"
    }
  ],
  "ignoredConfigs": []
}
```

:::note

For security reasons, [configuration variables](../../../operate-and-manage/configuration/static-configuration/configuring-declaratively.mdx#variables) and templating are disabled by default in the <Variable name="enterprise-product-name"/> REST API. You can enable them by starting members with the system property `-Dhazelcast.rest.allow.config.templating=true`.

:::

## Step 2. Create map with new configuration

Access the `/map/{mapName}/{key}` POST endpoint to create the map and add an entry:

<Tabs groupId="using-curl--using-swagger-ui">
<TabItem value="using-curl" label="Using cURL">

```shell
curl -X POST \
  'http://localhost:8443/hazelcast/rest/api/v1/map/my-map/1' \
  -H 'Authorization: Bearer '"$JWT_TOKEN"'' \
  -H 'Content-Type: text/plain' \
  -d 'my-value'
```

</TabItem>
<TabItem value="using-swagger-ui" label="Using Swagger UI">

- Open the Swagger UI at `http://localhost:8443/swagger-ui/index.html`.
- Navigate to the `/map/{mapName}/{key}` POST endpoint under the **Data Controller** section.
- Click **Try it out**.
- Enter `my-map` and `1` in the 'mapName' and `key` fields respectively.
- Enter the value in the request body section:

  ```txt
  my-value
  ```
- Click **Execute**.

</TabItem>
</Tabs>

This action will create the map named `my-map` which matches the dynamically added config from the previous step.

You can use <Variable href="/management-center/{page-latest-supported-mc}/data-structures/map" text="Management Center"/> to verify that the map was successfully created with the expected configuration properties.

## Step 3. Create queue with new configuration

Access the `/queue/{queueName}` POST endpoint to create the queue and add an item:

<Tabs groupId="using-curl--using-swagger-ui">
<TabItem value="using-curl" label="Using cURL">

```shell
curl -X POST \
  'http://localhost:8443/hazelcast/rest/api/v1/queue/my-queue' \
  -H 'Authorization: Bearer '"$JWT_TOKEN"'' \
  -H 'Content-Type: text/plain' \
  -d 'item-1'
```

</TabItem>
<TabItem value="using-swagger-ui" label="Using Swagger UI">

- Open the Swagger UI at `http://localhost:8443/swagger-ui/index.html`.
- Navigate to the `/queue/{queueName}` POST endpoint under the **Data Controller** section.
- Click **Try it out**.
- Enter `my-queue` in the 'queueName' field.
- Enter the item value in the request body section:

  ```txt
  item-1
  ```
- Click **Execute**.

</TabItem>
</Tabs>

This step will create a queue named `my-queue` which matches the dynamically added config from the previous step.

You can use <Variable href="/management-center/{page-latest-supported-mc}/data-structures/queue" text="Management Center"/> to verify that the queue was successfully created with the expected configuration properties.

## Step 4 (Optional) Dynamically add new map by reloading configuration from disk

Modify the declarative configuration file to add a new map config and reload it using the `/cluster/config/reload` endpoint. For this tutorial, our config is located at `~/config`

<Tabs groupId="using-curl--using-swagger-ui">
<TabItem value="using-curl" label="Using cURL">

```shell
curl -X 'POST' \
  'http://localhost:8443/hazelcast/rest/api/v1/cluster/config/reload' \
  -H 'Authorization: Bearer '"$JWT_TOKEN"''
```

</TabItem>
<TabItem value="using-swagger-ui" label="Using Swagger UI">

- Open the Swagger UI at `http://localhost:8443/swagger-ui/index.html`.
- Navigate to the `/map/{mapName}/{key}` POST endpoint under the **Config Controller** section.
- Click **Try it out**.
- Click **Execute**.

</TabItem>
</Tabs>
