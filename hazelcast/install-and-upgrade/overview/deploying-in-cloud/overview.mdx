Deploy a Hazelcast cluster in cloud environments including Hazelcast <Variable name="hazelcast-cloud"/>, Amazon AWS, Google Cloud Platform, and Azure.

All these environments support the following features:

- Allow members to discover each other automatically without static IP configuration.
- Prevent data loss by creating partition backups in other Availability Zones (AZ).

## Hazelcast <Variable name="hazelcast-cloud"/> {/* #hazelcast-cloud */}

Deploy a Hazelcast application on <a href="/cloud/overview">Hazelcast <Variable name="hazelcast-cloud"/></a>.

Learn more about <a href="/cloud/developer-guide">developing applications for <Variable name="hazelcast-cloud"/></a>.

## Hazelcast AWS {/* #hazelcast-cloud-discovery-plugins-aws */}

Deploy a Hazelcast application on [Amazon Web Services](https://aws.amazon.com/).

To deploy a cluster on Amazon EC2, ECS/EC2, or ECS/Fargate, see [Deploying a Cluster on Amazon AWS](./deploying-on-aws.mdx).

To deploy a cluster on Amazon EKS/Fargate or EKS/EC2, see [Deploying on Kubernetes](../../../develop-and-build/kubernetes/deploying-in-kubernetes.mdx).

## Hazelcast Azure {/* #hazelcast-cloud-discovery-plugins-azure */}

Deploy a Hazelcast application on [Microsoft Azure](https://azure.microsoft.com/):

- [Deploying a cluster on Azure Virtual Machines](./deploying-on-azure.mdx)
- [Deploying a cluster on Azure Kubernetes Service](../../../develop-and-build/kubernetes/deploying-in-kubernetes.mdx#discovering-members-in-kubernetes-automatically) (AKS)

## Hazelcast GCP {/* #hazelcast-cloud-discovery-plugins-gcp */}

Deploy a Hazelcast application on [Google Compute Engine](https://cloud.google.com/compute/):

- [Deploying a cluster on Compute Engine VM Instances](./deploying-on-gcp.mdx)
- [Deploying a cluster on Google Kubernetes Engine](../../../develop-and-build/kubernetes/deploying-in-kubernetes.mdx#discovering-members-in-kubernetes-automatically) (GKE)

## Hazelcast Kubernetes {/* #hazelcast-cloud-discovery-plugins-kubernetes */}

Deploy a Hazelcast application in [Kubernetes](https://kubernetes.io/) environments, including the following that we have tested: GKE, EKS, AKS, OpenShift, IBM Cloud, Minikube.

See [Deploying on Kubernetes](../../../develop-and-build/kubernetes/deploying-in-kubernetes.mdx).

## Other Cloud Environments

To deploy Hazelcast in other cloud environments, check our list of [supported cloud plugins](../../../frameworks-and-plugins/hazelcast-plugins/cloud-discovery.mdx).
