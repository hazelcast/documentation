The previous method of dynamically loading custom classes or domain classes from other members, or deploying your code from your client was known as User Code Deployment. This method has been deprecated and will be removed at the next major version. The legacy information for the deprecated User Code Deployment solution has been retained in this section for your reference.

User Code Namespaces is only available to Enterprise Edition users.

Hazelcast recommends that Enterprise Edition users migrate to User Code Namespaces to benefit from the improved and extended capabilities that it offers.

After the next major release, Community Edition users can either upgrade to Enterprise Edition, or add their resources to the Hazelcast member class paths.

For further information on migrating from User Code Deployment to User Code Namespaces, see the [Migrate from User Code Deployment](../ucn-migrate-ucd.mdx) topic.

For further information on upgrading to Hazelcast Platform from IMDG, see the [Upgrading from IMDG 3.12.x](../../../../install-and-upgrade/upgrade/upgrading-from-imdg-3.mdx) or [Upgrading from IMDG 4.x](../../../../install-and-upgrade/upgrade/upgrading-from-imdg-4.mdx) topics.
