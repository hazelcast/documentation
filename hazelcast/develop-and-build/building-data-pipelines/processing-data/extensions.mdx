Stage extensions provide a way to add more capabilities to Pipeline API. They maintain the familiar and convenient fluent API for defining the pipeline. Extensions are applied in the pipeline by [`using` transform](./transforms.mdx#_using).

## Builtin extensions {/* #_builtin_extensions */}

There are some extensions available in the Hazelcast distribution.

| Extension | Module | Batch/Streaming | Description |
| --- | --- | --- | --- |
| [PythonExtension](./python.mdx) | `hazelcast-jet-python` | batch, streaming | Fluent API for Python invocation |
| [IMapExtension](./map-transforms.mdx#_map_transforms) (<Badge type="enterprise" />) | `hazelcast-enterprise` | batch, streaming | Convenience methods for using IMaps in pipeline transformations |

## Custom extensions

It is possible to implement custom extensions. For a tutorial see [Create a Custom Stage Extension](./custom-extension.mdx).
