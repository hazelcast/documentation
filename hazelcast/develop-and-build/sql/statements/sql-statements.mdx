Hazelcast supports the following SQL statements. Explore the available statements and find more details about them.

## DML Statements

| Statement | Usage |
| --- | --- |
| [`SELECT`](/hazelcast/6.0-snapshot/sql/select) | Read data from a table. |
| [`SINK INTO/INSERT INTO`](/hazelcast/6.0-snapshot/sql/sink-into) | Add data to a map and/or forward data to other systems. |
| [`UPDATE`](/hazelcast/6.0-snapshot/sql/update) | Overwrite data in a table. |
| [`DELETE`](/hazelcast/6.0-snapshot/sql/delete) | Delete data from a table. |

## DDL Statements

| Statement | Usage |
| --- | --- |
| [`CREATE MAPPING`](/hazelcast/6.0-snapshot/sql/create-mapping) | Map a local or remote data object to a table that Hazelcast can access. |
| [`SHOW MAPPINGS`](/hazelcast/6.0-snapshot/sql/show-mappings) | Get the names of existing mappings. |
| [`DROP MAPPING`](/hazelcast/6.0-snapshot/sql/drop-mapping) | Remove a mapping. |
| [`CREATE VIEW`](/hazelcast/6.0-snapshot/sql/create-view) | Create a virtual table based on the result set of a SQL query. Views can be reused in other queries. |
| [`DROP VIEW`](/hazelcast/6.0-snapshot/sql/drop-view) | Delete a view. |
| [`CREATE DATA CONNECTION`](/hazelcast/6.0-snapshot/sql/create-data-connection) | Create the metadata required to connect to an external system for later use. |
| [`DROP DATA CONNECTION`](/hazelcast/6.0-snapshot/sql/drop-data-connection) | Delete a data connection. |
| [`SHOW RESOURCES`](/hazelcast/6.0-snapshot/sql/show-resources) | Get the names of accessible resources for a data connection. |
| [`CREATE INDEX`](/hazelcast/6.0-snapshot/sql/create-index) | Create a sorted, hash, or bitmap index for a given map. |

## Job Management

| Statement | Usage |
| --- | --- |
| [`CREATE JOB`](/hazelcast/6.0-snapshot/sql/create-job) | Create a job that is not tied to the client session. |
| [`ALTER JOB`](/hazelcast/6.0-snapshot/sql/alter-job) | Restart, suspend, or resume a job. |
| [`SHOW JOBS`](/hazelcast/6.0-snapshot/sql/show-jobs) | Get the names of all running jobs. |
| [`DROP JOB`](/hazelcast/6.0-snapshot/sql/drop-job) | Cancel a job. |
| [`CREATE OR REPLACE SNAPSHOT`](./create-snapshot.mdx) <Badge type="enterprise"/> | Create a snapshot of a running job so you can stop and restart it at a later date. |
| [`DROP SNAPSHOT`](./drop-snapshot.mdx) <Badge type="enterprise"/> | Drop an existing snapshot. |
