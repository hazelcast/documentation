## Connecting to Hazelcast <Variable name="hazelcast-cloud"/> with Hazelcast CLC {/* #connecting-to-hazelcast-cloud-with-hazelcast-clc */}

To use the Hazelcast CLC with Hazelcast <Variable name="hazelcast-cloud"/>, you need to authenticate with <Variable name="hazelcast-cloud"/> using your API secret and key. You can then import the configuration of the cluster that you want to connect to. No additional configuration is required.

## Before you Begin

You need the following:

- Hazelcast CLC
- A <Variable name="hazelcast-cloud"/> cluster
- <a href="/cloud/developer"><Variable name="hazelcast-cloud"/> API key and secret</a>

## Authenticating with <Variable name="hazelcast-cloud"/> {/* #authenticating-with-cloud */}

To allow the Hazelcast CLC to do cluster operations, you must generate a <Variable name="hazelcast-cloud"/> token.

1. Execute the following command to retrieve the token.

   ```bash
   clc cloud login
   ```
2. When prompted, enter your API key and secret. If both are correct, the token is retrieved and saved.

## List Accessible Clusters

Run the following command to list the clusters linked to your <Variable name="hazelcast-cloud"/> account:

```bash
clc cloud list-clusters
```

For each cluster, the following attributes are displayed in order: Cluster ID, Cluster Name, Current Status, Hazelcast Version.

## Importing the Cluster Configuration

Import the configuration of the <Variable name="hazelcast-cloud"/> cluster that you want to connect to.

1. Run the following command to save the cluster configuration with the name `dev`. Replace the `$CLUSTER_NAME` placeholder with the name of your cluster.

   ```bash
   clc cloud import-config $CLUSTER-NAME --name dev
   ```
2. Start an interactive shell session.

   ```bash
   clc -c dev
   ```

The Hazelcast CLC will start in interactive mode, and you should see a command prompt. You're ready to start managing <a href="/clc/5.5.0/clc-cloud"><Variable name="hazelcast-cloud"/> clusters</a>.

:::note

The Hazelcast CLC connects to the cluster on demand, that is when you issue a command that requires the connection, such as running a SQL query.

:::
