## New Features

- Added the `--timeout` flag which causes Hazelcast CLC to exit with status code 2 if an operation cannot be completed in the given time.

## Improvements

- Added a workaround for a server side bug that causes an incorrect hash calculation error when certain type of Jet jars are submitted. See: [https://github.com/hazelcast/hazelcast/pull/24674](https://github.com/hazelcast/hazelcast/pull/24674)
- Extended cluster information retrieved from 'clc viridian get-cluster' command.
- Improved error checking so a token error is displayed when a Cloud command fails with an authentication error.
