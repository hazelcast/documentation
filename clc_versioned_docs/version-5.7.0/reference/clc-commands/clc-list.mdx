Usage:

```bash
clc list [command] [flags]
```

## `clc list add`

Add a value in the given list.

Usage:

```bash
clc list add [value] [flags]
```

Parameters:

| Parameter | Required | Description | Default |
| --- | --- | --- | --- |
| `--name, -n` | Optional | Name of the list. | `default` |
| `value,` | Required | Value to set for the key. | N/A |
| `--value-type, -v` | Optional | Data type of the value. One of: `string`, `bool`, `json`, `i8`, `i16`, `i32`, `i64`, `f32`, `f64` | String |
| `--index` | Optional | Index for the value | N/A |

Example:

```bash
clc list add --name example-list --value-type i16 10 --index 1
```
