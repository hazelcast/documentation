This Maven plugin is a Java development tool for testing and deploying [cluster-side modules](/cloud/cluster-side-modules).

:::note

This plugin is for Cloud Standard clusters only.

:::

## Before you Begin

Make sure that you have the following:

- [Maven](https://maven.apache.org/install.html)
- The `JAVA_HOME` environment variable set to the path of your JDK

  :::note

  Hazelcast Cloud requires JDK 17 or later.

  :::

## Usage Example

```xml
<build>
    <plugins>
        <plugin>
            <groupId>com.hazelcast.cloud</groupId>
            <artifactId>hazelcast-cloud-maven-plugin</artifactId>
            <version>0.2.0</version>
            <configuration>
                <apiBaseUrl>https://api.cloud.hazelcast.com</apiBaseUrl>
                <clusterId>${clusterId}</clusterId>
                <apiKey>${apiKey}</apiKey>
                <apiSecret>${apiSecret}</apiSecret>
            </configuration>
        </plugin>
    </plugins>
</build>
```
