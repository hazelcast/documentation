You can restrict access to your cluster to allow only authorized clients to connect to it.

## Cloud Standard {/* #cloud-standard */}

If you’re using a Cloud Standard cluster, you can add your client IP addresses to a [whitelist](/cloud/ip-white-list).

## Cloud Dedicated {/* #cloud-dedicated */}

Cloud Dedicated clusters are private by default to prevent attacks such as denial of service. To authorize clients to connect to your clusters, you must set up VPC peering. Contact the support team for full details.
