Before clusters can execute or store your [cluster-side modules](/cloud/cluster-side-modules), they need to be packaged into a single file and uploaded to the cluster as custom classes. You can upload cluster-side modules, using the console, or the Maven plugin.

## Before you Begin

Check the [requirements and limitations](/cloud/cluster-side-modules#prereqs,) for cluster-side modules to make sure that your code is ready to be packaged.

## Uploading Cluster-Side Modules {/* #package */}

Clusters expect all modules to be packaged into a single ZIP or JAR file. When you've built and packaged your cluster-side modules, the final step is to upload the resulting package file to the cluster.

You can upload custom classes, using the following options:

- Maven plugin
- Cloud console

### Using the Maven Plugin

<Badge type="serverless"/>

1. [Configure the Cloud Maven plugin](/cloud/maven-plugin-hazelcast) in your `pom.xml` file.
2. Change into your project's root directory.
3. Execute the `deploy` goal to package your project into a JAR file and upload it to the configured cluster.

   ```bash
   mvn clean package hazelcast-cloud:deploy
   ```

In the output, you should see that the plugin packaged and deployed your JAR to your Cloud Standard cluster.

### Using the Cloud Console

To upload code to Cloud:

1. Use your build tool such as Gradle or Maven to package the classes into a JAR or ZIP file.
2. Sign into the <LinkVariable name="page-cloud-console">Cloud console</LinkVariable> and select your cluster.
3. Go to **Manage** \> **Custom Classes** and upload your file to Cloud.

When the file is uploaded and ready to use, you will see a success message.

## Removing Cluster-Side Modules

To remove cluster-side modules from the cluster, you must use the Cloud console.

1. Sign into the <LinkVariable name="page-cloud-console">Cloud console</LinkVariable> and select your cluster.
2. Go to **Manage** \> **Custom Classes** and find your class in the list.
3. Click on the delete icon next to the class that you want to delete.

## Downloading Cluster-Side Modules

To download a cluster-side module, you must use the Cloud console.

1. Sign into the <LinkVariable name="page-cloud-console">Cloud console</LinkVariable>.
2. Go to **Manage** \> **Custom Classes**, find your class in the **Uploaded Classes** list and click on it.
