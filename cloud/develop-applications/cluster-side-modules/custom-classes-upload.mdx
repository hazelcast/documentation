Before clusters can execute or store your [cluster-side modules](./overview.mdx), they need to be packaged into a single file and uploaded to the cluster as custom classes. You can upload cluster-side modules, using the console, or the Maven plugin.

## Before you Begin

Check the [requirements and limitations](./overview.mdx#prereqs,) for cluster-side modules to make sure that your code is ready to be packaged.

## Uploading Cluster-Side Modules {/* #package */}

Clusters expect all modules to be packaged into a single ZIP or JAR file. When you've built and packaged your cluster-side modules, the final step is to upload the resulting package file to the cluster.

You can upload custom classes, using the following options:

- Maven plugin
- <Variable name="hazelcast-cloud"/> console

### Using the Maven Plugin

<Badge type="serverless"/>

1. <a href="/cloud/maven-plugin-hazelcast">Configure the <Variable name="hazelcast-cloud"/> Maven plugin</a> in your `pom.xml` file.
2. Change into your project's root directory.
3. Execute the `deploy` goal to package your project into a JAR file and upload it to the configured cluster.

   ```bash
   mvn clean package hazelcast-cloud:deploy
   ```

In the output, you should see that the plugin packaged and deployed your JAR to your <Variable name="hazelcast-cloud"/> Standard cluster.

### Using the <Variable name="hazelcast-cloud"/> Console {/* #using-the-cloud-console */}

To upload code to <Variable name="hazelcast-cloud"/>:

1. Use your build tool such as Gradle or Maven to package the classes into a JAR or ZIP file.
2. Sign into the <Variable href="{page-cloud-console}" text="{hazelcast-cloud} console"/> and select your cluster.
3. Go to **Manage** \> **Custom Classes** and upload your file to <Variable name="hazelcast-cloud"/>.

When the file is uploaded and ready to use, you will see a success message.

## Removing Cluster-Side Modules

To remove cluster-side modules from the cluster, you must use the <Variable name="hazelcast-cloud"/> console.

1. Sign into the <Variable href="{page-cloud-console}" text="{hazelcast-cloud} console"/> and select your cluster.
2. Go to **Manage** \> **Custom Classes** and find your class in the list.
3. Click on the delete icon next to the class that you want to delete.

## Downloading Cluster-Side Modules

To download a cluster-side module, you must use the <Variable name="hazelcast-cloud"/> console.

1. Sign into the <Variable href="{page-cloud-console}" text="{hazelcast-cloud} console"/>.
2. Go to **Manage** \> **Custom Classes**, find your class in the **Uploaded Classes** list and click on it.
