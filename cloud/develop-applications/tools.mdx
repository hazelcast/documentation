Hazelcast provides a variety of developer tools for creating, testing and debugging applications.

## Client Libraries {/* #client-libraries */}

You can use any of the following clients to connect to Hazelcast Cloud clusters: Java, Python, .NET, (CLC) CLI or (SQL) CLI.

See [Clients and Languages](https://hazelcast.com/clients/) for available libraries.

## Hazelcast Command-Line Client {/* #hazelcast-command-line-client */}

The [Hazelcast Command-Line Client (CLC)](/clc/5.5.1/overview) introduces a new set of commands specially designed for connecting to and managing your Cloud clusters.

## Maven Plugin for Cloud Standard {/* #maven-plugin-for-cloud-standard */}

The Maven plugin for Cloud Standard is a Java development tool for testing and deploying cluster-side modules on Cloud Standard clusters.

See [maven-plugin-hazelcast.adoc](/cloud/maven-plugin-hazelcast).
