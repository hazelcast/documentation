Hazelcast provides a variety of developer tools for creating, testing and debugging applications.

## Client Libraries

You can use any of the following clients to connect to Hazelcast <Variable name="hazelcast-cloud"/> clusters: Java, Python, .NET, (CLC) CLI or (SQL) CLI.

See [Clients and Languages](https://hazelcast.com/clients/) for available libraries.

## Hazelcast Command-Line Client

The [Hazelcast Command-Line Client (CLC)](/clc/5.5.1/overview) introduces a new set of commands specially designed for connecting to and managing your <Variable name="hazelcast-cloud"/> clusters.

## Maven Plugin for <Variable name="hazelcast-cloud"/> Standard {/* #maven-plugin-for-cloud-standard */}

The Maven plugin for <Variable name="hazelcast-cloud"/> Standard is a Java development tool for testing and deploying cluster-side modules on <Variable name="hazelcast-cloud"/> Standard clusters.

See [Hazelcast Cloud Maven Plugin](/cloud/maven-plugin-hazelcast).
