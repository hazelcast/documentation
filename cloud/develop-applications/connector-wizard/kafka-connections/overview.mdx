To query data in a Kafka source or sink using SQL, you need to [create a data connection](./create-kafka-connection.mdx) from your <Variable name="hazelcast-cloud" /> cluster to your Kafka broker, and a mapping to the topic data you want to query. The easiest way to do this is to use the connector wizard.

Use these topics to create and maintain data connections and associated mappings:

- [Creating a Data Connection to Kafka](./create-kafka-connection.mdx)
- [Adding a Mapping to a Kafka Data Connection](./add-kafka-mapping.mdx)
- [Deleting a Data Connection to Kafka](./delete-kafka-connection.mdx)
