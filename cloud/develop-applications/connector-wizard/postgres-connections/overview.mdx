To query data in a PostgreSQL source or sink using SQL, you need to [create a data connection](/cloud/create-postgres-connection) from your Cloud cluster to the database instance, and a mapping to the data you want to query. The easiest way to do this is to use the connector wizard.

Use these topics to create and maintain data connections and associated mappings:

- [Creating a Data Connection to PostgreSQL](/cloud/create-postgres-connection)
- [Adding a Mapping to a PostgreSQL Data Connection](/cloud/add-postgres-mapping)
- [Deleting a Data Connection to PostgreSQL](/cloud/delete-postgres-connection)
