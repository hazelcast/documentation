To query data in a PostgreSQL source or sink using SQL, you need to [create a data connection](./create-postgres-connection.mdx) from your <Variable name="hazelcast-cloud" /> cluster to the database instance, and a mapping to the data you want to query. The easiest way to do this is to use the connector wizard.

Use these topics to create and maintain data connections and associated mappings:

- [Creating a Data Connection to PostgreSQL](./create-postgres-connection.mdx)
- [Adding a Mapping to a PostgreSQL Data Connection](./add-postgres-mapping.mdx)
- [Deleting a Data Connection to PostgreSQL](./delete-postgres-connection.mdx)
