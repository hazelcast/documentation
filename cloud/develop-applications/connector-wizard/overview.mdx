Hazelcast <Variable name="hazelcast-cloud"/> has a built-in connector wizard, which simplifies the process of connecting to external data sources. For supported platforms, the connector wizard removes the need to write or install a platform-specific connector.

The connector wizard helps you to set up, test, and save a secure data connection to a data source or sink from a <Variable name="hazelcast-cloud"/> cluster. It also guides you through the process of creating a mapping to selected data resources. The mapping allows you to query any of the selected data using SQL.

From the connector wizard, you can also add mappings to existing data connections and run guided demos.

## Supported Connections

The connector wizard currently supports connections to the following platforms:

- [Kafka](/cloud/kafka-connections)
- [PostgreSQL](/cloud/postgres-connections)
- [Hazelcast IMap](/cloud/imap-connections) - This connector makes it easier to create mappings to IMaps already written to a <Variable name="hazelcast-cloud"/> cluster.

You can also set up your own data connections to the following platforms in SQL or programmatically:

- [MySQL using a JDBC connection](/hazelcast/latest/data-connections/data-connections-configuration#JDBC)
- [MongoDB](/hazelcast/latest/data-connections/data-connections-configuration#Mongo)
