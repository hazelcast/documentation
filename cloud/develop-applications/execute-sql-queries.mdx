You can open a SQL shell in your cluster and submit SQL queries directly from a web browser.

Before you can start querying data, you must do the following:

- If your data is in an existing map on the cluster, create a mapping to it first. To do this, either execute a [`CREATE MAPPING` statement](/hazelcast/latest/sql/create-mapping), or use the [connector wizard](./connector-wizard/overview.mdx).
- If your data is in an external system, you can create a data connection to it. To do this, either execute a [`CREATE DATA CONNECTION` statement](/hazelcast/latest/sql/create-data-connection), or use the [connector wizard](./connector-wizard/overview.mdx).

## Executing Your First Query

To submit a SQL query:

1. Sign into the <Variable href="{page-cloud-console}" text="{hazelcast-cloud} console" /> and select your cluster.
2. Go to **SQL**.
3. Click **Compose New Query**.
4. Enter your SQL query and execute it.

Your query syntax is saved, and any data resources accessed via mappings or data connections are added to the Data Explorer for future use.
