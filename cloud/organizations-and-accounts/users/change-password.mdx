When logging in using a username and password, Hazelcast recommends that you change your password regularly.

To change your password, complete the following steps:

1. Open the <Variable href="{page-cloud-console}" text="{hazelcast-cloud} console"/>
2. Select **Account** from the side navigation bar
3. Select **Password** from the **Account** options

   The Account Settings screen displays.
4. Enter the password that you used when signing in to the console in the **Current Password** text box
5. Enter the password that you want to use when signing in next time in the **New Password** text box
6. Enter the new password again in the **Confirm New Password**
7. Select the **CHANGE** button

   Your password is updated, and a confirmation box displays to confirm the change.
