Organization users can view the name of the organization with which their sign in is associated. They cannot change the name.

:::note

If you want to change the name of the organization, this must be done by the admin user. For further information on changing the name of the organization, see the [Update Organization Name](/cloud/update-organization-name) topic.

:::

To view the organization name, complete the following steps:

1. Open the <Variable href="{page-cloud-console}" text="{hazelcast-cloud} console"/>
2. Select **Account** from the side navigation bar
3. Select **Organization** from the **Account** options

   The organization name displays.
