Each user has a role assigned to them. The role defines the permissions granted to that user.

The current user roles are as follows:

- Admin user. This is the user who set up the organization account
- Organization user. This is any user who has been added to the organization by the admin user

All users have the following permissions:

- Manage their own clusters. This allows users to work with Hazelcast, for example to:

  - [Create clusters](/cloud/create-clusters)
  - [Pause clusters](/cloud/stop-and-resume#pausing-a-cluster)
  - [Resume clusters](/cloud/stop-and-resume#resuming-a-cluster)
  - [Delete clusters](/cloud/deleting-a-cluster)
  - [Create backups](/cloud/backup-and-restore)
  - [Upload custom classes](/cloud/custom-classes-upload#package)
  - [Configure data structures](/cloud/data-structures)
- [Use Management Center](https://docs.hazelcast.com/management-center/latest/getting-started/overview)
- [View the organization name](/cloud/view-organization-details)
- [View and update their own profile](/cloud/view-and-update-profile)
- [Enable and disable Multi-factor Authentication](/cloud/multi-factor-authentication)

In addition, admin users have the following permissions:

- [Invite user](/cloud/invite-user)
- [Delete user](/cloud/remove-user)
- [Manage billing and payments](/cloud/payment-methods)
- [Delete the organization account](/cloud/delete-account)

Admin users can see all clusters. If an organization user is removed, the admin user inherits ownership of the related clusters and resources.

When updates are made, for example to the state of a cluster or to an organization user's name, there might be a delay between the change being made and the view presented to the admin user.
