You can create a cluster for development or production.

## Before you Begin

You need a [Cloud account](/cloud/create-account).

To create a cluster, you must add a [payment card](/cloud/payment-methods) to your account.

## Using the Cloud Console

<Tabs>
<TabItem value="development-cluster" label="Development cluster">

To create a development cluster, do the following:

1. Sign into the <Variable href="{page-cloud-console}" text="Cloud console"/>.
2. Click **Create New Cluster**.
3. Click **Create Cluster**.
4. Select **Development**.
5. Update the cluster name if you want to. You cannot change the cluster name after the cluster is created.
6. Click **Start Development Cluster**.
7. Wait while your cluster is created. When the cluster is up and running, a **Quick Connection Guide** is displayed with instructions for connecting a sample client to it.

:::note

Development clusters are [paused](/cloud/stop-and-resume#pausing-a-cluster) automatically when you don't connect to the cluster for 24 hours.

:::

</TabItem>
<TabItem value="production-cluster" label="Production cluster">

To create a production cluster, do the following:

1. Sign into the <Variable href="{page-cloud-console}" text="Cloud console"/>.
2. Click **Create New Cluster**.
3. Click **Create Cluster**.
4. Click **Production**.
5. Update the cluster name if you want to. You cannot change the cluster name after the cluster is created.
6. Click **Start Production Cluster**
7. Wait while your cluster is created. When the cluster is up and running, a **Quick Connection Guide** is displayed with instructions for connecting a sample client to it.

:::note

Production clusters are [paused](/cloud/stop-and-resume#pausing-a-cluster) automatically if you don't have a payment method set up *and* you don't connect to your cluster for 24 hours.

:::

</TabItem>
</Tabs>
