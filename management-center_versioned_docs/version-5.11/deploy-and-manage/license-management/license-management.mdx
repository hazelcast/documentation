To use some features in Management Center, you need a valid Enterprise license.

## Licensed features

For a list of Management Center's Enterprise features, see the [Overview](../../get-started/overview.mdx#key-features-and-benefits).

To use these features, you must install (in Management Center) either an Enterprise license for Management Center or an Enterprise license for Hazelcast Platform.

As well as these Management Center features, you need an Enterprise license for Hazelcast Platform on your cluster to use the following features in Management Center:

- WAN Replication
- Persistence (Hot Restart)
- Rolling Upgrade

## View cluster licenses

To view details about an Enterprise license for Hazelcast Platform that's installed on your cluster, see [View a cluster license](../../cluster/administration/cluster-license.mdx).

## Update Management Center licenses

To update an Enterprise license for Management Center, see [Update an Enterprise License for Management Center](./updating-mc-license-ui.mdx).

## Update cluster licenses at runtime

You can use Management Center to update an existing Enterprise license in your Hazelcast cluster. See [Update cluster configuration at runtime](../../cluster/administration/update-config.mdx).

Or, for other ways to update a license, see the [Hazelcast Platform documentation](/hazelcast/latest/deploy/enterprise-licenses).
