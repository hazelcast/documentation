You can see a list of all the [fenced locks](/hazelcast/latest/data-structures/fencedlock) in your cluster by clicking on the **Fenced Locks** menu item in the left menu.

![Fenced Locks View](../images/FencedLocks.png)

A fenced lock has two fixed metrics:

- **Acquire Limit**: Maximum number of reentrant acquires, which is configured in the CP member's [`lock-acquire-limit`](/hazelcast/latest/cp-subsystem/configuration#fencedlock-configuration) option.
- **Lock Count**: Total number of times the lock has been acquired.

If the lock is held by an endpoint, the following additional metrics are displayed:

- **Owner Session Id**: [Session](./dashboard.mdx#session) ID of the lock owner.
- **Owner**: Address of the lock owner.

Sort the table by clicking on the column headers.
