You can use the **Persistence** tab of the **Administration** menu item to manage Hazelcast clusters that have persistence enabled.

This page is available only to admin users.

<table>
<colgroup>
<col style={{width:'20%'}} />
<col style={{width:'80%'}} />
</colgroup>
<thead>
<tr>
<th>Field</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td>**Cluster Status**</td>
<td>

The start status of a cluster that has persistence enabled. After a cluster-wide restart, the start status can be one of the following:

- **Succeeded**: The cluster is up and running in an `ACTIVE` state.
- **In-Progress**: The cluster is missing members and cannot yet restart. The cluster is in a `PASSIVE` state.

</td>
</tr>
<tr>
<td>**Force-Start Cluster**</td>
<td>Trigger a force-start. See [Trigger a force-start](./triggering-force-start.mdx).</td>
</tr>
<tr>
<td>**Partial-Start Cluster**</td>
<td>Trigger a partial-start. See [Trigger a partial-start](./triggering-partial-start.mdx).</td>
</tr>
<tr>
<td>**Hot Backup**</td>
<td>Trigger a partial-start. See [Trigger hot backups](./triggering-hot-backup.mdx).</td>
</tr>
<tr>
<td>**Data Recovery Policy**</td>
<td>The data recovery policy that's configured in the cluster's <Variable href="/hazelcast/{page-latest-supported-hazelcast}/storage/configuring-persistence#persistence-cluster-data-recovery-policy" text="cluster-data-recovery-policy" code /> configuration option.</td>
</tr>
<tr>
<td>**Remaining Data Load Time**</td>
<td>A countdown from the value configured in the cluster's <Variable href="/hazelcast/{page-latest-supported-hazelcast}/storage/configuring-persistence#persistence-data-load-timeout-seconds" text="data-load-timeout-seconds" code /> configuration option.</td>
</tr>
<tr>
<td>**Remaining Validation Time**</td>
<td>A countdown from the value configured in the cluster's <Variable href="/hazelcast/{page-latest-supported-hazelcast}/storage/configuring-persistence#persistence-validation-timeout-seconds" text="validation-timeout-seconds" code /> configuration option.</td>
</tr>
</tbody>
</table>
