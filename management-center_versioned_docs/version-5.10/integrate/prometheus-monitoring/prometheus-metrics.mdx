Management Center automatically reformats all <Variable href="/hazelcast/{page-latest-supported-hazelcast}/list-of-metrics" text="Hazelcast cluster metrics" /> for compatibility with Prometheus.

In addition, Management Center updates a subset of metrics to align with Prometheus best practice recommendations. This makes it easier to construct complex queries, build dashboards, and work alongside metrics from other applications.

## Metrics versions

By default, Management Center exposes two versions of the <Variable href="/hazelcast/{page-latest-supported-hazelcast}/list-of-metrics" text="Hazelcast Metrics" />:

**Version 1 (V1) metrics** apply a basic transformation for compatibility with Prometheus:
  - Replace `.`, `:`, and `-` with `_`
  - Add `hz_` prefix

Every Platform metric is included in the V1 output.

**Version 2 (V2) metrics** apply an advanced transformation for conformity with [Prometheus naming conventions](https://prometheus.io/docs/practices/naming/):
  - Use `snake_case`
  - Add `hazelcast_` prefix
  - Take each metric name from a fixed list in Management Center
  - Combine related metrics and add labels
  - Convert to recommended base units:
    - Time in seconds
    - Memory in bytes
    - Percentages as ratios (for example, 50% converts to 0.5)
  - Append units to metric names
  - Remove unit labels
  - Append `_total` to accumulated metrics

V2 output contains only the metrics in that list. A metric that is not in the list appears only in V1 output.

The tables on this page list only the metrics that have a version 2 (V2) name.

In some cases, several V1 metrics are combined into a single V2 metric differentiated by labels. For example, `hazelcast_map_operations_total` replaces `hz_map_getCount` and `hz_map_setCount` by adding `operation="get"` and `operation="set"` labels.

### Examples

This table compares four map metrics in V1 and V2:

| V1 metric | V2 metric | V2 labels | V2 value |
| --- | --- | --- | --- |
| `hz_map_queryCount` | `hazelcast_map_queries_total` | No `unit` label | Same as V1 |
| `hz_map_creationTime` | `hazelcast_map_creation_timestamp_seconds` | No `unit` label | Seconds instead of milliseconds |
| `hz_map_totalMaxRemoveLatency` | `hazelcast_map_latency_max_seconds` | `operation="remove"` instead of `unit` | Seconds instead of milliseconds |
| `hz_map_totalPutLatency` | `hazelcast_map_latency_seconds_total` | `operation="put"` instead of `unit` | Seconds instead of milliseconds |

This is how they would look as `/metrics` output:

```none
# queryCount in V1 and V2
hz_map_queryCount{name="map-1",mc_member="127.0.0.1:5701",mc_cluster="Cluster-1",unit="COUNT",} 0.0 1737715903399
hazelcast_map_queries_total{name="map-1",mc_member="127.0.0.1:5701",mc_cluster="Cluster-1",} 0.0 1737715903399

# creationTime in V1 and V2
hz_map_creationTime{name="map-1",mc_member="127.0.0.1:5701",mc_cluster="Cluster-1",unit="MS",} 1.737715861118E12 1737715903399
hazelcast_map_creation_timestamp_seconds{name="map-1",mc_member="127.0.0.1:5701",mc_cluster="Cluster-1",} 1.737715861118E9 1737715903399

# totalMaxRemoveLatency in V1 and V2
hz_map_totalMaxRemoveLatency{name="map-1",mc_member="127.0.0.1:5701",mc_cluster="Cluster-1",unit="MS",} 0.0 1737715903399
hazelcast_map_latency_max_seconds{name="map-1",mc_member="127.0.0.1:5701",mc_cluster="Cluster-1",operation="remove",} 0.0 1737715903399

# totalPutLatency in V1 and V2
hz_map_totalPutLatency{name="map-1",mc_member="127.0.0.1:5701",mc_cluster="Cluster-1",unit="MS",} 2019.0 1743601193973
hazelcast_map_latency_seconds_total{name="map-1",mc_member="127.0.0.1:5701",mc_cluster="Cluster-1",operation="put",} 2.019 1743601193973
```

### Change the metrics version {/* #config */}

To change which set of metrics is exposed to Prometheus, update the `hazelcast.mc.prometheusExporter.printers` system property:

- V1 and V2 (default): `hazelcast.mc.prometheusExporter.printers=V1,V2`
- V1 only: `hazelcast.mc.prometheusExporter.printers=V1`
- V2 only: `hazelcast.mc.prometheusExporter.printers=V2`

See [System properties and environment variables](../../deploy-and-manage/configuration/system-properties.mdx).

:::important

If you set the property to `V2`, Management Center will only expose the subset of metrics that have updated versions available.

:::
