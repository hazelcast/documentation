## New Features

There are no new features in this release.

## Fixes

- Fixed: demo generate-data wikipedia-event-stream command doesn't progress [448](https://github.com/hazelcast/hazelcast-commandline-client/issues/448).
- Updated [go-git](https://github.com/go-git/go-git) to v5.13.2. That fixes [CVE-2025-21613](https://nvd.nist.gov/vuln/detail/CVE-2025-21613). Note that CLC doesn't run any servers, so this CVE is not exploitable in any version of CLC.
- Updated [/golang.org/x/crypto](https://pkg.go.dev/golang.org/x/crypto) to v0.41.0. That fixes [CVE-2024-45337](https://nvd.nist.gov/vuln/detail/CVE-2024-45337). Note that CLC doesn't run any servers, so this CVE is not exploitable in any version of CLC.
- Updated builder to Go version 1.25. That fixes [CVE-2025-22871](https://nvd.nist.gov/vuln/detail/CVE-2025-22871). Note that CLC doesn't run any servers, so this CVE is not exploitable in any version of CLC.
