The Hazelcast CLC supports the following keyboard shortcuts in the shell (interactive) mode.

| Key Binding | Description |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> or <kbd>Home</kbd> | Go to the beginning of the line. |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> or <kbd>End</kbd> | Go to the end of the line. |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> or <kbd>Up</kbd> | Previous command in history. |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> or <kbd>Down</kbd> | Next command in history. |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> or <kbd>Right</kbd> | Forward one character. |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> or <kbd>Left</kbd> | Backward one character. |
| <kbd>Ctrl</kbd>+<kbd>H</kbd> or <kbd>Backspace</kbd> | Delete character before the cursor. |
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | Cut the word before the cursor to the clipboard. |
| <kbd>Ctrl</kbd>+<kbd>U</kbd> | Cut the line before the cursor to the clipboard. |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Cancel running command. |
| <kbd>Alt</kbd>+<kbd>F</kbd> | Go forward to the beginning of the next word. |
| <kbd>Alt</kbd>+<kbd>B</kbd> | Go back to the beginning of the previous word. |
