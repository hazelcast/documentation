Executes a SQL statement.

Usage:

```bash
clc sql [query] [flags]
```

Parameters:

| Parameter | Required | Description | Default |
| --- | --- | --- | --- |
| `--use-mapping-suggestion` | Optional | Executes the proposed `CREATE MAPPING` suggestion and retries the query. | `false` |

## Querying with SQL using the Hazelcast CLC

You can run SQL queries in both interactive and non-interactive mode of the Hazelcast CLC.

<Tabs groupId="interactive-mode--non-interactive-mode">
<TabItem value="non-interactive-mode" label="Non-Interactive mode">

```bash
$ clc sql -c prod "SELECT * from cities"
---------------------------------------------------------------------------------
      __key | country                   | city                      | population
---------------------------------------------------------------------------------
          1 | United Kingdom            | London                    |    9540576
          4 | United States             | Los Angeles               |    3985520
          5 | Turkey                    | Ankara                    |    5309690
          7 | Brazil                    | Sao Paulo                 |   22429800
---------------------------------------------------------------------------------
```

</TabItem>
