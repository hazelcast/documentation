This command group provides commands for doing various operations on Hazelcast <Variable name="hazelcast-cloud" />, such as creating and managing clusters.

All commands except `cloud login` require the generation of a token using an API key and secret, which you can retrieve from the <Variable name="hazelcast-cloud" /> console. Running `cloud login` prompts you for this information, and creates and saves the token.

Usage:

```bash
clc cloud [command] [options]
```

## clc cloud login

Logs in to <Variable name="hazelcast-cloud" /> using the given API key and API secret and retrieves a token. The token is cached to be used by other commands. If not specified, the key and the secret will be asked in a prompt.

Alternatively, you can use the following environment variables:

- `CLC_CLOUD_API_KEY`
- `CLC_CLOUD_API_SECRET`

Usage:

```bash
clc cloud login [flags]
```

Parameters:

| Parameter | Required | Description | Default |
| --- | --- | --- | --- |
| `--api-key` | Optional | Sets the API key. Overrides the `CLC_CLOUD_API_KEY` environment variable. If not given, an input prompt is shown. |  |
| `--api-secret` | Optional | Sets the API secret. Overrides the `CLC_CLOUD_API_SECRET` environment variable. If not given, an input prompt is shown. |  |

## clc cloud create-cluster

Creates a <Variable name="hazelcast-cloud" /> cluster.

Make sure you authenticate to the <Variable name="hazelcast-cloud" /> API using `cloud login` before running this command.

Usage:

```bash
clc cloud create-cluster [flags]
```

Parameters:

| Parameter | Required | Description | Default |
| --- | --- | --- | --- |
| `--api-key` | Optional | Sets the API key. Overrides the `CLC_CLOUD_API_KEY` environment variable. If not given, one of the existing API keys will be used. |  |
| `--name` | Optional | Sets the name of the created cluster. If not given, an auto-generated name will be used. |  |
| `--development` | Optional | Creates a development cluster. |  |
| `--prerelease` | Optional | Creates the cluster with a prerelease image. |  |

## clc cloud stream-logs

Outputs the logs of the given <Variable name="hazelcast-cloud" /> cluster as a stream.

Make sure you authenticate to the <Variable name="hazelcast-cloud" /> API using `cloud login` before running this command.

The log format may be one of:

- minimal: Only the log message
- basic: Time, level and the log message
- detailed: Time, level, thread, logger and the log message
- free form template, see: [https://pkg.go.dev/text/template](https://pkg.go.dev/text/template) for the format. You can use the following placeholders: `msg`, `level`, `time`, `thread` and `logger`. Usage:

```bash
clc cloud stream-logs [cluster-ID/name] [flags]
```

Parameters:

| Parameter | Required | Description | Default |
| --- | --- | --- | --- |
| `--api-key` | Optional | Sets the API key. Overrides the `CLC_CLOUD_API_KEY` environment variable. If not given, one of the existing API keys will be used. |  |
| `--log-format` | Optional | Format of log lines. Either a predefined or free form format. | `basic` |
