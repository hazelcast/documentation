## `clc atomicreference clear`

Deletes the `AtomicReference` value.

Usage:

```bash
clc atomicreference clear [flags]
```

Parameters:

| Parameter | Required | Description | Default |
| --- | --- | --- | --- |
| `--name, -n` | Optional | Name of the AtomicReference. | `default` |

## `clc atomicreference compare-and-set`

Sets the value for the given key if it has the expected value.

Usage:

```bash
clc atomicreference compare-and-set [expected value] [new value] [flags]
```

Parameters:

| Parameter | Required | Description | Default |
| --- | --- | --- | --- |
| `--name, -n` | Optional | Name of the AtomicReference. | `default` |
| `expected value,` | Required | Old value of the atomic reference. | N/A |
| `new value,` | Required | New value of the atomic reference. | N/A |
| `--value-type, -v` | Optional | Data type of the value. One of: `string`, `bool`, `json`, `i8`, `i16`, `i32`, `i64`, `f32`, `f64` | string |
| `--show-type` | Optional | Add a type column to the output. | `false` |

<details>
<summary>Global parameters</summary>

<PartialGlobalParameters />

</details>

Example:

```bash
clc atomicreference --name ref1 compare-and-set previous-value next-value
```

## `clc atomicreference destroy`

Deletes the `AtomicReference` and related data. Once destroyed, an `AtomicReference` with the same name cannot be used.

Usage:

```bash
clc atomicreference destroy [flags]
```

Parameters:

| Parameter | Required | Description | Default |
| --- | --- | --- | --- |
| `--name, -n` | Optional | Name of the atomic reference. | `default` |
| `--yes` | Optional | Skip confirming the destroy operation. | `false` |
