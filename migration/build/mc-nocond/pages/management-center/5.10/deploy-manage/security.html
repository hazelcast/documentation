To secure Management Center, you can encrypt communications using TLS/SSL, secure user sessions, set up user login authentication, and enable audit logging.

TLS/SSL

You can configure Management Center to communicate over TLS/SSL for secure, encrypted traffic. See TLS/SSL.

User sessions

To secure users' sessions, you can configure session timeouts and user login attempts. See Secure user sessions.

User security providers

To authenticate user logins, you can choose from a variety of security providers, including a local one or third-party ones such as LDAP. See Security Providers.

Logging

To keep a record of events such as user logins, you can configure Management Center to keep an audit log. See Audit Logging.
