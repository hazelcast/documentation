This page provides an overview of the exported snapshots of the Hazelcast Streaming jobs. To create a new export, see Job Management.

Here are the descriptions of parameters:

  • Name: Given name of the exported snapshot.

  • Job Name: Name of the job.

  • Job ID: ID of the job.

  • Creation Time: Creation time of the export.

  • Size: Size of the exported snapshot.

You can click on the trash icon to delete any exported snapshots. Note that you need to be an admin user to execute this action.
