You can monitor data structures in your cluster using the *Storage*, *Compute*, and *Messaging* menus in Management Center.

Storage

Under the Storage menu, you’ll find the following pages:

  • Map. Here, you can also set the selected map’s attributes.

  • Cache

  • Replicated Map

  • MultiMap

  • Lock

  • Flake ID Generator

  • PN Counter

Compute

Under the Compute menu, you’ll find the following pages:

  • Executor

Messaging

Under the Messaging menu, you’ll find the following pages:

  • Queue

  • Topic

  • Reliable Topic
