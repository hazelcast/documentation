You can use security providers to authenticate users in Management Center and allow them to log into user accounts.

Management Center comes with the following security providers:

  • Dev mode: No login required. One admin user. No authentication token needed to use the REST API.

  • Local: Manage user logins and authentication in Management Center.

    You can create and manage users both in the Management Center UI and with the hz-mc conf tool only if you use the local security provider.

  • Active Directory: Use an existing Active Directory server for user authentication and authorization.

  • JAAS: Use your own javax.security.auth.spi.LoginModule implementation for user authentication and authorization.

  • LDAP: Use an existing Active Directory server for user authentication and authorization.

  • SAML: Use SAML single sign-on with Management Center.

  • OpenID Connect: Use OpenID Connect single sign-on with Management Center.

You can select dev mode as a security provider only when you first launch Management Center. To configure all other security providers, go to Settings > Security Providers.

If you’re looking to switch from one security provider to another, see Switching to a New Security Provider.
