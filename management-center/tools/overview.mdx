This section describes how to use the tools offered by Management Center:

Test

- [SQL Browser](./sql-browser.mdx) to run SQL queries and operate on the data structures.
- [Scripting](./scripting.mdx) to run scripts on the cluster using languages including JavaScript, Groovy, Ruby and Python.
- [Clustered REST](../integrate/clustered-rest/clustered-rest.mdx) to retrieve statistical cluster information using REST API.
- [Console](./console.mdx) to perform operations on the cluster's data structures by running single-line commands, mostly for development and testing purposes.
