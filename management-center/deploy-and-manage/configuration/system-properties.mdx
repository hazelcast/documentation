You can use system properties and environment variables to configure many aspects of Management Center, from JMX to the home directory and feature flags. These properties give you the power to tweak settings at startup without having to configure anything in the UI.

If a property has no environment variable, you can set it with the `JAVA_OPTS` environment variable. You can use `JAVA_OPTS` when you start Management Center in any of these ways:
- Docker environments
- `hz-mc conf` tool
- Start scripts included with Hazelcast Platform or Management Center, such as `hz-mc start`

:::tip[Docker configuration]

You may also need to use other environment variables in Docker environments. For the Docker reference, see [DockerHub](https://hub.docker.com/r/hazelcast/management-center).

:::

You can use properties to configure both Management Center and Management Center's client connection strategy on startup.

If a property has an environment variable, the Environment variable column lists it.

This example shows how to set system properties or environment variables:

<Tabs groupId="mc-property-method">
<TabItem value="option" label="Command-line option">

```bash
hz-mc start -Dhazelcast.mc.http.port=8083
```

</TabItem>
<TabItem value="java-opts" label="JAVA_OPTS">

```bash
export JAVA_OPTS='-Dhazelcast.mc.http.port=8083'
hz-mc start
```

</TabItem>
<TabItem value="env" label="Environment variable">

```bash
export MC_HTTP_PORT=8083
hz-mc start
```

</TabItem>
</Tabs>

## Web server

These properties configure the Management Center web server, including the HTTP port, health check, and CORS:

| Property | Environment variable | Default | Description |
| --- | --- | --- | --- |
| <Anchor id="hazelcast-mc-contextpath" />`hazelcast.mc.contextPath` | `MC_CONTEXT_PATH` | `' '` (empty) | Prefix of all URL paths in Management Center. |
| <Anchor id="hazelcast-mc-cors-allowed-origin-patterns" />`hazelcast.mc.cors.allowedOriginPatterns` | `MC_CORS_ALLOWED_ORIGIN_PATTERNS` |  | A list of origins patterns for which cross-origin requests are allowed. |
| <Anchor id="hazelcast-mc-cors-allowed-methods" />`hazelcast.mc.cors.allowedMethods` | `MC_CORS_ALLOWED_METHODS` |  | HTTP methods to allow for cross-origin requests.<br/><br/>If any other `hazelcast.mc.cors.*` property is set while `hazelcast.mc.cors.allowedMethods` is not set, only `GET` and `HEAD` HTTP methods will be allowed. |
| <Anchor id="hazelcast-mc-cors-allowed-headers" />`hazelcast.mc.cors.allowedHeaders` | `MC_CORS_ALLOWED_HEADERS` |  | List of headers that a pre-flight request can list as allowed for use during an actual request.<br/><br/>The special value `*` allows actual requests to send any header. |
| <Anchor id="hazelcast-mc-cors-exposed-headers" />`hazelcast.mc.cors.exposedHeaders` | `MC_CORS_EXPOSED_HEADERS` |  | List of response headers that an actual response might have and can be exposed to the client.<br/><br/>The special value `*` allows all headers to be exposed. |
| <Anchor id="hazelcast-mc-cors-allow-credentials" />`hazelcast.mc.cors.allowCredentials` | `MC_CORS_ALLOW_CREDENTIALS` |  | Whether user credentials are supported or not. Setting this property to `true` forbids originPatterns, allowedMethods, allowedHeaders to have a `*` value. Be aware that this option establishes a high level of trust with the configured domains and also increases the surface attack of the web application by exposing sensitive user-specific information such as cookies and CSRF tokens. If this property is not set, user credentials are not supported. |
| <Anchor id="hazelcast-mc-cors-allow-private-network" />`hazelcast.mc.cors.allowPrivateNetwork` | `MC_CORS_ALLOW_PRIVATE_NETWORK` |  | Whether private network access is supported for user-agents restricting such access by default.<br/><br/>Private network requests are requests whose target server's IP address is more private than that from which the request initiator was fetched. For example, a request from a public website (`https://example.com`) to a private website (`https://router.local`), or a request from a private website to localhost.<br/><br/>If this property is not set, private network access is not supported. |
| <Anchor id="hazelcast-mc-cors-max-age" />`hazelcast.mc.cors.maxAge` | `MC_CORS_MAX_AGE` |  | Configure how long, in seconds, the response from a pre-flight request can be cached by clients. |
| <Anchor id="hazelcast-mc-forwarded-requests-enabled" />`hazelcast.mc.forwarded.requests.enabled` | `MC_FORWARDED_REQUESTS_ENABLED` | `true` | Whether Management Center reads `X-Forwarded-*` headers from reverse proxies. |
| <Anchor id="enabling-health-check-endpoint" /><Anchor id="hazelcast-mc-healthcheck-enable" />`hazelcast.mc.healthCheck.enable` | `MC_HEALTH_CHECK_ENABLED` | `false` | Whether the `/health` endpoint is enabled on port [`hazelcast.mc.http.port`](#hazelcast-mc-http-port) + 1. This endpoint is always served over HTTP, regardless of any TLS/SSL settings. This endpoint responds with `200 OK` HTTP status code if Management Center is running. |
| <Anchor id="hazelcast-mc-healthcheck-port" />`hazelcast.mc.healthCheck.port` | `MC_HEALTH_CHECK_PORT` | [`hazelcast.mc.http.port`](#hazelcast-mc-http-port) + 1 | The port on which the `/health` endpoint is exposed. |
| <Anchor id="hazelcast-mc-hostaddress" />`hazelcast.mc.hostAddress` | `MC_HOST_ADDRESS` | `0.0.0.0` (all network interfaces) | Network address that Management Center is reachable on. |
| <Anchor id="hazelcast-mc-http-port" />`hazelcast.mc.http.port` | `MC_HTTP_PORT` | `8080` | HTTP port for Management Center. |
| <Anchor id="hazelcast-mc-websocket-buffer-size" />`hazelcast.mc.websocket.buffer-size` | `HAZELCAST_MC_WEBSOCKET_BUFFER_SIZE` | `5MB` | The buffer size of the WebSocket connection MC uses for SQL operations. |

If none of `hazelcast.mc.cors.*` properties are set, all origins are allowed to make cross-origin HTTP requests, but WebSocket connection could be established only from the same origin.

For `hazelcast.mc.cors.allowedHeaders` and `hazelcast.mc.cors.exposedHeaders`, a header name is not required to be listed if it is one of: `Cache-Control`, `Content-Language`, `Expires`, `Last-Modified`, or `Pragma`.
