You can use system properties and environment variables to configure many aspects of Management Center, from JMX to the home directory and feature flags. These properties give you the power to tweak settings at startup without having to configure anything in the UI.

If a property has no environment variable, you can set it with the `JAVA_OPTS` environment variable. You can use `JAVA_OPTS` when you start Management Center in any of these ways:
- Docker environments
- `hz-mc conf` tool
- Start scripts included with Hazelcast Platform or Management Center, such as `hz-mc start`

:::tip[Docker configuration]

You may also need to use other environment variables in Docker environments. For the Docker reference, see [DockerHub](https://hub.docker.com/r/hazelcast/management-center).

:::

You can use properties to configure both Management Center and Management Center's client connection strategy on startup.

If a property has an environment variable, the Environment variable column lists it.

This example shows how to set system properties or environment variables:

<Tabs groupId="mc-property-method">
<TabItem value="option" label="Command-line option">

```bash
hz-mc start -Dhazelcast.mc.http.port=8083
```

</TabItem>
<TabItem value="java-opts" label="JAVA_OPTS">

```bash
export JAVA_OPTS='-Dhazelcast.mc.http.port=8083'
hz-mc start
```

</TabItem>
<TabItem value="env" label="Environment variable">

```bash
export MC_HTTP_PORT=8083
hz-mc start
```

</TabItem>
</Tabs>

## General

These properties configure Management Center's configuration file, home directory, license, and general behavior:

| Property | Environment variable | Default | Description |
| --- | --- | --- | --- |
| `hazelcast.mc.auditlog.enabled` | `MC_AUDITLOG_ENABLED` | `false` | Whether Management Center logs auditable events. See [Audit Logging](./logging.mdx#audit-logging). |
| `hazelcast.mc.config.file` | `HAZELCAST_MC_CONFIG_FILE` |  | Path to a YAML declarative configuration file that Management Center applies automatically before it starts. See [YAML declarative configuration (Beta)](./declarative-configuration/overview.mdx). |
| `hazelcast.mc.configReplacer.class` |  |  | Full class name of a variable replacer to use. See [Variable replacers](./variable-replacers.mdx). |
| `hazelcast.mc.configReplacer.failIfValueMissing` |  | `true` | Whether the configuration loading process stops when a replacement value is missing. |
| `hazelcast.mc.home` | `MC_HOME` |  | Home directory where metrics, executed SQL queries, and configuration settings are saved. See [Configure Management Center](./configuring.mdx). |
| `hazelcast.mc.license` | `MC_LICENSE` |  | Enterprise license. When this property is set, the license takes precedence over one that is set in the user interface, and you cannot update the license in the UI. For more details about licenses, see [Enterprise licenses](../license-management/license-management.mdx). |
| `hazelcast.mc.lock.skip` | `MC_LOCK_SKIP` | `false` | Whether the `hz-mc conf` tool does not check for an `mc.lock` file in the home directory. See [Skipping the Check for a Lock File](./mc-conf.mdx#skip-the-check-for-a-lock-file). |
| `hazelcast.mc.phone.home.enabled` | `MC_PHONE_HOME_ENABLED` | `true` | Whether Management Center sends usage data to the Hazelcast phone home server. See [Usage analytics](../phone-homes.mdx). |
| `hazelcast.mc.rest.enabled` | `MC_REST_ENABLED` | `false` | Enable [clustered REST](../../integrate/clustered-rest/clustered-rest.mdx) endpoints. |

## Web server

These properties configure the Management Center web server, including the HTTP port, health check, and CORS:

| Property | Environment variable | Default | Description |
| --- | --- | --- | --- |
| `hazelcast.mc.contextPath` | `MC_CONTEXT_PATH` | `' '` (empty) | Prefix of all URL paths in Management Center. |
| `hazelcast.mc.cors.allowedOriginPatterns` | `MC_CORS_ALLOWED_ORIGIN_PATTERNS` |  | A list of origins patterns for which cross-origin requests are allowed. |
| `hazelcast.mc.cors.allowedMethods` | `MC_CORS_ALLOWED_METHODS` |  | HTTP methods to allow for cross-origin requests.<br/><br/>If any other `hazelcast.mc.cors.*` property is set while `hazelcast.mc.cors.allowedMethods` is not set, only `GET` and `HEAD` HTTP methods will be allowed. |
| `hazelcast.mc.cors.allowedHeaders` | `MC_CORS_ALLOWED_HEADERS` |  | List of headers that a pre-flight request can list as allowed for use during an actual request.<br/><br/>The special value `*` allows actual requests to send any header. |
| `hazelcast.mc.cors.exposedHeaders` | `MC_CORS_EXPOSED_HEADERS` |  | List of response headers that an actual response might have and can be exposed to the client.<br/><br/>The special value `*` allows all headers to be exposed. |
| `hazelcast.mc.cors.allowCredentials` | `MC_CORS_ALLOW_CREDENTIALS` |  | Whether user credentials are supported or not. Setting this property to `true` forbids originPatterns, allowedMethods, allowedHeaders to have a `*` value. Be aware that this option establishes a high level of trust with the configured domains and also increases the surface attack of the web application by exposing sensitive user-specific information such as cookies and CSRF tokens. If this property is not set, user credentials are not supported. |
| `hazelcast.mc.cors.allowPrivateNetwork` | `MC_CORS_ALLOW_PRIVATE_NETWORK` |  | Whether private network access is supported for user-agents restricting such access by default.<br/><br/>Private network requests are requests whose target server's IP address is more private than that from which the request initiator was fetched. For example, a request from a public website (`https://example.com`) to a private website (`https://router.local`), or a request from a private website to localhost.<br/><br/>If this property is not set, private network access is not supported. |
| `hazelcast.mc.cors.maxAge` | `MC_CORS_MAX_AGE` |  | Configure how long, in seconds, the response from a pre-flight request can be cached by clients. |
| `hazelcast.mc.forwarded.requests.enabled` | `MC_FORWARDED_REQUESTS_ENABLED` | `true` | Whether Management Center reads `X-Forwarded-*` headers from reverse proxies. |
| `hazelcast.mc.healthCheck.enable` | `MC_HEALTH_CHECK_ENABLED` | `false` | Whether the `/health` endpoint is enabled on port `hazelcast.mc.http.port` + 1. This endpoint is always served over HTTP, regardless of any TLS/SSL settings. This endpoint responds with `200 OK` HTTP status code if Management Center is running. |
| `hazelcast.mc.healthCheck.port` | `MC_HEALTH_CHECK_PORT` | `hazelcast.mc.http.port` + 1 | The port on which the `/health` endpoint is exposed. |
| `hazelcast.mc.hostAddress` | `MC_HOST_ADDRESS` | `0.0.0.0` (all network interfaces) | Network address that Management Center is reachable on. |
| `hazelcast.mc.http.port` | `MC_HTTP_PORT` | `8080` | HTTP port for Management Center. |
| `hazelcast.mc.websocket.buffer-size` | `HAZELCAST_MC_WEBSOCKET_BUFFER_SIZE` | `5MB` | The buffer size of the WebSocket connection MC uses for SQL operations. |

If none of `hazelcast.mc.cors.*` properties are set, all origins are allowed to make cross-origin HTTP requests, but WebSocket connection could be established only from the same origin.

For `hazelcast.mc.cors.allowedHeaders` and `hazelcast.mc.cors.exposedHeaders`, a header name is not required to be listed if it is one of: `Cache-Control`, `Content-Language`, `Expires`, `Last-Modified`, or `Pragma`.

## Client connection strategy configuration {/* #client-config */}

Use the following properties to configure the connection strategy of the Management Center client.

These properties apply to all clients that are started by Management Center.

| Property | Default | Description |
| --- | --- | --- |
| `hazelcast.mc.client.max.backoff.millis` | `30000` | Upper limit of the backoff in milliseconds. Values must be between 30000 and 600000. |
| `hazelcast.mc.client.backoff.multiplier` | `2` | Factor by which to multiply the backoff after each failed retry. Values must be between 1 and 10. |
| `hazelcast.mc.client.initial.backoff.millis` | `1000` | Duration in milliseconds that Management Center waits after the first connection failure before retrying. Values must be between 1000 and 60000. |
| `hazelcast.mc.clientFiltering.modes` | `ALLOWLIST, DENYLIST` | Adjusts client filtering modes. Value must be set of `ALLOWLIST` and `DENYLIST`. |
| `hazelcast.mc.info.instanceName` |  | Set the instance name visible in the [Top Bar](../../get-started/user-interface-overview/user-interface.mdx#top-bar). Set blank to not display any instance name. If not set the instance name defaults to the hostname of the machine Manage Center is deployed on. |
| `maskOpts` | `' '` (empty) | Comma-separated list of option keys to be masked. Masks sensitive data in logs passed via JAVA\_OPTS. |
